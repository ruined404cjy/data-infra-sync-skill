# 将部分同步状态交由用户或 Agent 接管

`data-infra-sync-skill` 只自动执行常见且可证明安全的同步路径。同步首次修改工作树或本地引用后发生失败时，CLI 返回 `partial`，报告实际 HEAD、工作树、已完成项和失败阶段，由用户或 agent 将仓库恢复到可识别的稳定状态后重新检查。执行阶段由当次进程管理，跨进程处理从实际 Git 状态重新开始。

首版受控构建补丁自动化限于 DataInfra 当前声明的单个 Delta 补丁。多个补丁、补丁依赖、补丁定义变化和状态无法唯一判定时，CLI 返回显式处理状态并保留现场。

该边界保留同步前置检查、常见路径自动化和结构化诊断的主要收益，并控制恢复状态组合带来的代码与测试规模。部分失败由用户或 agent 完成有限的 Git 判断；相同命令仅在重新检查后满足稳定前置条件时执行。
